# ☕ Support

LLM Privacy Gateway is a spare-time project: no company behind it, no ads, no telemetry, no paid tier, no investor to report to. If it saves you time at work — or keeps somebody else's sensitive data off an untrusted relay — you can chip in.

**Support is entirely optional.** Every feature stays free and available to everyone, whether you tip or not.

## Ways to help

| | |
| --- | --- |
| ⭐ **Star the repo** | Free, and it is what actually gets the project seen |
| 🐞 **Report a bug, open a pull request** | Frequently worth more than money |
| 📣 **Tell somebody who needs it** | Costs nothing |
| ☕ **Send a tip** | QR codes below |

## Tips

Both codes are static and can be scanned repeatedly. Use the app that matches the code.

  <img src="assets/wechat-pay.png" alt="WeChat Pay QR code" width="230" />

  <img src="assets/alipay.png" alt="Alipay QR code" width="230" />

| App | How to scan |
| --- | --- |
| **WeChat Pay** | WeChat → **+** (top right) → **Scan** |
| **Alipay** | Alipay → **Scan** |

Each card is a plain rendering of the maintainer's own payment link. Scan it with the matching app and check the payee name before you confirm.

Both apps need an account with a mainland Chinese bank card attached, so they are mainly practical if you already use them day to day.

## Other ways to send something

Outside China the two apps above are inconvenient. If you would rather use a different route — GitHub Sponsors, Ko-fi, Buy Me a Coffee, PayPal — open an issue and say so. The list here follows actual demand rather than guesses.

## Transparency

There is no business behind this repository and no plan to start one. Nothing received buys a roadmap slot, a license change, or priority support. It buys the maintainer some time to keep the thing working, and that is all it is.

## Thank you

Every star, issue, patch and tip is appreciated. Bug reports especially — they are the cheapest way to make this project better for everybody.
