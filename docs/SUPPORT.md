## Ways to help

Starring and reporting cost nothing, and they usually help more than money does.

| | What | Why it matters |
| :---: | :--- | :--- |
| ⭐ | **Star the repository** | Free, and it is what actually gets the project in front of people |
| 🐞 | **Report a bug, open a pull request** | Frequently worth more than a tip |
| 📣 | **Tell somebody who needs it** | Costs nothing, reaches exactly the right person |
| ☕ | **Send a tip** | Optional — codes below |

Each card is a plain rendering of the maintainer's own payment link. Scan it with the matching app and check the payee name before you confirm.

<details>
<summary><b>Outside mainland China?</b></summary>

Both apps above need an account with a mainland Chinese bank card attached, so they are mainly practical if you already use them day to day.

If you would rather use another route — GitHub Sponsors, Ko-fi, Buy Me a Coffee, PayPal — open an issue and say so. The list here follows actual demand rather than guesses.

## Transparency

There is no business behind this repository and no plan to start one. Nothing received buys a roadmap slot, a license change, or priority support.

It buys the maintainer some time to keep the thing working, and that is all it is.

## Thank you

Every star, issue, patch and tip is appreciated. Bug reports especially — they are the cheapest way to make this project better for everybody.
