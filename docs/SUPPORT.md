## Using it at work?

There is nothing to buy, and this is not a soft way of saying otherwise. The licence is [Apache 2.0](../LICENSE), which already covers commercial use: no per-seat fee, no request to file, no tier, and no feature that paying unlocks.

The one obligation is attribution. If you are redistributing this — which includes bundling it into something your company ships — keep [NOTICE](../NOTICE) and [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md) with it. That second file also records what the libraries you install require, and it is the part an internal legal review will actually ask about.

## Transparency

A tip buys nothing except time: no private build, no roadmap slot, no priority support, and no licence — because no licence is needed. Features are not gated and will not be.

That is the whole model. Apache-2.0 for everyone, a tip jar for whoever wants one, the same software either way. This is a spare-time project, and the tip jar is what keeps it going.

## Thank you

Every star, issue, patch and tip is appreciated. Bug reports especially — they are the cheapest way to make this project better for everybody.
