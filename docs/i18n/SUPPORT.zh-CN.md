## 可以怎么帮忙

下面四件事都是实打实的帮忙。其中只有打赏要花钱，也只有它能直接变成维护时间 —— 这一页真正想说的就是它。

| | 做什么 | 为什么有用 |
| :---: | :--- | :--- |
| ⭐ | **给项目点个 Star** | 不花钱，而且真正能让项目被更多人看到 |
| 🐞 | **提 Bug、发 PR** | 很多时候比打赏更有价值 |
| 📣 | **转给需要的人** | 零成本，而且能精准触达 |
| ☕ | **打赏** | 最直接地为这个项目争取更多时间 —— 见下方收款码 |

## 要在公司里用？

没有什么需要买的，这句话没有言外之意。许可证是 [Apache 2.0](../../LICENSE)，本身就覆盖商业用途：没有按人头收费、没有需要提交的申请、没有档位，也没有哪个功能要靠付费解锁。

唯一的要求是署名。如果你要再分发它 —— 包括把它打包进公司对外交付的东西里 —— 请把 [NOTICE](../../NOTICE) 与 [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md) 一并保留。后者还记录了你安装的那些库各自有什么要求，而这正是内部法务审查真正会问的部分。

## 说明

打赏除了时间什么都买不到：换不来私有版本、路线图优先权、优先技术支持，也换不来授权 —— 因为根本不需要授权。功能没有被锁，也不会被锁。

整个模式就是这样：Apache 2.0 给所有人，钱箱留给想给的人，两边拿到的是同一份软件。这是业余项目，而正是这个钱箱让它还能继续。
