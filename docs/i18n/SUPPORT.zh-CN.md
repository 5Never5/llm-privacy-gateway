## 可以怎么帮忙

下面四件事都是实打实的帮忙。其中只有打赏能直接变成维护时间 —— 这一页真正想说的也就是它。

| | 做什么 | 为什么有用 |
| :---: | :--- | :--- |
| ⭐ | **给项目点个 Star** | 不花钱，而且真正能让项目被更多人看到 |
| 🐞 | **提 Bug、发 PR** | 很多时候比打赏更有价值 |
| 📣 | **转给需要的人** | 零成本，而且能精准触达 |
| ☕ | **打赏** | 最直接地为这个项目争取更多时间 —— 见下方收款码 |

## 打赏

两个收款码都是静态码，可以重复扫码。用对应的应用扫即可 —— **绿框是微信支付，蓝框是支付宝**。

| 应用 | 扫码方式 |
| :--- | :--- |
| **微信支付** | 微信 → 右上角 **+** → **扫一扫** |
| **支付宝** | 支付宝 → **扫一扫** |

两张卡片都是收款方本人支付链接的纯图形呈现。用对应的应用扫，确认收款人名称后再支付。

如果你更希望用别的方式支持 —— GitHub Sponsors、Ko-fi、Buy Me a Coffee、PayPal —— 开一个 issue 告诉我即可。这里的清单会跟着实际需求走，而不是靠猜。
