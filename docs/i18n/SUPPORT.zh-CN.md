## 可以怎么帮忙

下面五件事都是实打实的帮忙。其中只有打赏和授权能直接变成维护时间 —— 这一页真正想说的也就是它们。

| | 做什么 | 为什么有用 |
| :---: | :--- | :--- |
| ⭐ | **给项目点个 Star** | 不花钱，而且真正能让项目被更多人看到 |
| 🐞 | **提 Bug、发 PR** | 很多时候比打赏更有价值 |
| 📣 | **转给需要的人** | 零成本，而且能精准触达 |
| 🧾 | **购买商业授权** | 如果受益的是公司 —— 见[商业用途](COMMERCIAL.zh-CN.md) |
| ☕ | **打赏** | 面向个人；最直接地为这个项目争取更多时间 —— 见下方收款码 |

## 要在公司里用？

**别打赏，去买授权。** 打赏是个人的心意；而公司把这个软件用于自身业务，需要的是商业授权。买一份授权既是更正当的做法，也是打赏永远做不到的那种支撑。

按申请单独报价、一次性费用，两种情形下的软件完全相同 —— 没有任何功能被锁，授权买的是许可，不是能力。[商业用途](COMMERCIAL.zh-CN.md)写了详细说明，申请只需开一个 issue。

想先在内部试用再决定？说一声，通常可以免费出具一份限期评估许可 —— 这样试点就在许可范围内，而不是待在灰色地带。

## 打赏

## 说明

卖的是许可，不是访问权限。[PolyForm 非商业许可证 1.0.0](../../LICENSE) 让个人、教育、科研、慈善与政府用途免费；商业用途需要授权，这条界线由[商业用途](COMMERCIAL.zh-CN.md)精确划定。

所以打赏除了时间什么都买不到 —— 换不来私有版本、路线图优先权或者优先技术支持。功能没有被锁，也不会被锁。

整个模式就是这样：对公司一份授权，对个人一个钱箱，同一份软件给两边。这是业余项目，而正是这两者让它还能继续。
