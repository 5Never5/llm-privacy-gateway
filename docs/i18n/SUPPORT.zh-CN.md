# ☕ 支持本项目

LLM Privacy Gateway 是一个业余项目：背后没有公司，没有广告，没有遥测，没有付费版本，也没有需要汇报的投资人。如果它帮你在工作中省下了时间，或者让某些敏感数据没有落到不可信的第三方接口上，可以请我喝杯咖啡。

**打赏完全出于自愿。** 无论是否打赏，所有功能对所有人都保持免费可用。

## 可以怎么帮忙

| | |
| --- | --- |
| ⭐ **给个 Star** | 不花钱，而且真正能让项目被更多人看到 |
| 🐞 **提 Bug、发 PR** | 很多时候比给钱更有价值 |
| 📣 **转给需要的人** | 零成本 |
| ☕ **打赏** | 见下方收款码 |

## 打赏

两个收款码都是静态码，可以重复扫码。用对应的应用扫即可。

| 应用 | 扫码方式 |
| --- | --- |
| **微信支付** | 微信 → 右上角 **+** → **扫一扫** |
| **支付宝** | 支付宝 → **扫一扫** |

两张卡片都是收款方本人支付链接的纯图形呈现。用对应的应用扫，确认收款人名称后再支付。

两个应用都需要绑定中国大陆银行卡，所以通常是你本来就在用才方便。

## 其他方式

如果你更希望用别的方式支持 —— GitHub Sponsors、Ko-fi、Buy Me a Coffee、PayPal —— 开一个 issue 告诉我即可。这里的清单会跟着实际需求走，而不是靠猜。

## 说明

这个仓库背后没有商业实体，也没有打算做。收到的任何支持都不会换来路线图优先权、授权条款变更或者优先技术支持。它换来的只是维护者的一些时间，用来让这个项目继续能用，仅此而已。

## 谢谢

每一个 Star、issue、补丁和打赏都很珍贵。尤其是 Bug 反馈 —— 这是让项目对所有人都更好用最省力的方式。
