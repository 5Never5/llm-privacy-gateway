# 商业用途

**一句话：个人、教育、科研、慈善与政府用途免费。在公司内部使用，或者把它放进你要卖的东西里，需要取得授权。**

这不是功能门槛。许可证管的是**谁可以把它用于商业目的**，不是软件能做什么 —— 只有一个版本，两种情形下的软件完全相同。

## 什么时候需要授权

| 情形 | 是否需要授权 |
| :--- | :--- |
| 个人项目、学习、爱好，或没有商业目的的测试 | 不需要 |
| 教学、学术研究、慈善机构、公共研究机构、公共安全或卫生机构、政府机构 | 不需要 |
| 公司内部推广使用 —— 哪怕只是用来脱敏自家合同 | **需要** |
| 打包进你要销售的产品或服务 | **需要** |
| 你运营的、供其他组织使用的付费平台 | **需要** |
| 向付费客户交付的咨询、代理或法律工作 | **需要** |

分界点不是"有没有就这个软件本身付过钱"，而是这次**使用行为是否服务于商业目的** —— 所以公司在内部免费使用，仍然需要授权。

[PolyForm 非商业许可证 1.0.0](../../LICENSE) 正文对免费情形写得很具体：个人使用、慈善组织、教育机构、公共研究机构、公共安全与卫生机构、环境保护组织、政府机构，无论其资金来源如何，都属于获准目的。

## 商业授权授予什么

- 永久、全球范围、**非独占**的权利，可出于商业目的使用、修改与分发本软件
- 覆盖公司及其关联方 —— 包括内部部署、付费客户工作，以及嵌入你销售的产品
- 同一份软件：无功能限制、无授权码、无激活、无遥测
- 所授权版本，以及授权有效期内发布的所有更新

每次授权的条款以书面约定为准。本页说明的是标准方案，真正有约束力的是签署的那份协议。

## 费用

按申请单独报价，一次性费用。影响报价的就两件事：有多少人会用到，以及它最终是否被放进你要卖的东西里。

不需要订阅，也不按人数计量。如果报出的数字对你不合适，直接说 —— 范围小的部署通常对应更小的数字，定这个价的目的本来就是让"付"比"不付"更省事。

## 怎么申请

开一个 **[商业授权申请](https://github.com/5Never5/llm-privacy-gateway/issues/new?template=commercial-license.yml)**，说明打算怎么用、大概多少人会用到。之后沟通会转到非公开渠道，你会拿到一份可以交给相关同事看的书面授权。

没有销售流程：不约电话、不走采购流程表演、不需要预约演示。这是个人项目，文书刻意做得很短。

**已经在商业使用但还没有授权？** 说出来，而不是消失。你将要接受的这份许可证本身规定，在收到书面通知后有 32 天的整改期 —— 这也是它希望被理解的用意：谈一份授权，总比吵一架容易。

## 拿不准的话

就在同一个地方问。问一句从来不收费，而且一个直接的回答通常比走一遍内部法务审查更快。如果结论是你并不需要授权，那也完全是个好结果。

## 试用

如果公司想先认真试一轮再决定，通常可以免费出具一份限期评估许可 —— 说一声，并说明你想验证什么。这样试点就在许可范围内，而不是待在灰色地带。

## 版本沿革

| 版本 | 许可证 |
| :--- | :--- |
| 本次换证之前发布的版本 | MIT —— 就那些副本永久保有当时授予的权利，无法撤回 |
| 本次变更及之后的版本 | PolyForm 非商业许可证 1.0.0，或商业授权 |
